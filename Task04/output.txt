Precedence
  2 ** 3 ** 2 = 512 (right-associative)
  -2 ** 2     = -4 (** binds tighter than unary minus)
  (-2) ** 2   = 4

Floating-point step error
  (4.2 - 3.5) / 0.1        = 7.000000000000002
  round((4.2 - 3.5) / 0.1) = 7

round() vs int() vs math.floor()
   -2.5: round=-2  int=-2  floor=-3
   -2.4: round=-2  int=-2  floor=-3
   -2.6: round=-3  int=-2  floor=-3
    2.5: round=2  int=2  floor=2

Fat steps and rate for 4.2% and 3.1% (SNF 8.5, 10 litres)
  fat 4.2: raw=7.000000000000002  round=7  int=7  floor=7
     round -> rate 32.80  payment 328.00
     int   -> rate 32.80  payment 328.00
     floor -> rate 32.80  payment 328.00
  fat 3.1: raw=-3.999999999999999  round=-4  int=-3  floor=-4
     round -> rate 28.40  payment 284.00
     int   -> rate 28.80  payment 288.00
     floor -> rate 28.40  payment 284.00

Comparison chaining and Boolean operators
  2.0 <= fat <= 7.0           : True
  fat >= 2.0 and fat <= 7.0   : True
  not (2.0 <= 7.5 <= 7.0)     : True
